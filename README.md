# Back-End II

Projeto de aprendizado desenvolvido durante meus primeiros estudos em **APIs RESTful com Node.js e Express**.

Neste projeto, implementei rotas básicas, simulei requisições HTTP e pratiquei a estruturação de um back-end organizado.

---

## 🎯 Objetivos do projeto

- Entender os verbos HTTP (GET, POST, PUT, DELETE)
- Criar rotas utilizando Express.js
- Simular um CRUD básico
- Trabalhar com Middlewares e Controllers
